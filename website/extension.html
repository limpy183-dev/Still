Still · Website focus.

A small extension for Chrome and Edge. It puts distracting websites on hold, gives them a daily limit and a bedtime, and shows a calm page instead. It works on its own, on any computer. For more control on Windows, we recommend adding Still for Windows too.

Add to Chrome, it’s freeUsing Still for Windows?
On its own

Everything for websites, right in your browser.

Click the Still icon in the toolbar to open its settings. There’s nothing else to install, and it works on Windows, Mac, Linux and ChromeOS.

Focus sessions

Add the websites that pull you in and start a session. They stay on hold until it ends, including tabs you already have open.

Daily limits

Give a website a daily allowance. When it’s used up, the site rests until midnight. Several tabs of one site count once.

Bedtime

Choose a window, such as 22:30 to 07:00, and the websites you pick rest overnight.

Calm block screens

Garden, Dusk or Paper, your own words and image, or send blocked visits to a page you choose.

Stays in your browser

No account, no analytics. Your lists and settings stay in that browser profile, and matching uses the browser’s own rules.

Gentle by design

On its own, a session can be ended from the settings page whenever you need to. For sessions that can’t be ended early, add Still for Windows.

WITH STILL FOR WINDOWS

Better together.

On its own, the extension only blocks websites. On Windows, we recommend adding Still for Windows: the extension becomes its browser companion, and the app’s sessions block apps and websites together and can stay locked until they end.

  • Sessions you can’t end early, with an optional wait before release
  • Scheduled alerts that start a session at a set time
  • Browser policies as a fallback, including private and guest windows
  • Both sides only add blocks: the stricter limit wins, and neither releases what the other holds
  • Your own sessions and limits in the extension keep working alongside the app’s

Set it up in Still

  1. In Still, choose Settings → Set up browser companion. Still opens this extension’s store page.
  2. Choose Add to Chrome. In Edge, allow extensions from other stores first.
  3. In the extension’s Details, turn on Allow in incognito (Chrome) or Allow in InPrivate (Edge).
  4. Repeat for each browser profile you use, then restart the browser. The extension should say it’s connected.

Good to know

A few honest answers.

Which browsers?

Chrome and Microsoft Edge, and other Chromium browsers that install from the Chrome Web Store. In Edge, turn on Allow extensions from other stores when it asks.

Why these permissions?

To notice a blocked site in any tab and show your block screen there, the extension needs to see which websites your tabs open. It doesn’t upload your browsing history. Privacy details.

Something not working?

See Support for connection fixes, or open an issue on GitHub. The extension is open source, like the rest of Still.
