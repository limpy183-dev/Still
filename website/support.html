A little help getting back to focus

Something in the way? Let’s sort it out.

Help with Still and the Still · Website focus browser extension. Start with a quick fix below, or send us your question.

Ask for help on GitHubTry a quick fix

Start here

The browser extension is a companion to the Still Windows app. It needs the desktop app and Still Guard to connect and apply your focus sessions; installing the extension alone is not enough.

The extension isn’t connected, or a website session won’t start

  1. Install Still on a supported Windows 10 or Windows 11 PC. Finish any active session, then open Settings → Set up browser companion in Still to register the local connection.
  2. In Chrome, open chrome://extensions, find Still · Website focus and choose Details. Check that it is enabled, then turn on Allow in incognito. Still requires private-window access before a website session can start.
  3. Restart Chrome after setup. Check the Still extension’s tooltip for its connection status, and keep a connected browser window open when starting your session.

Use the companion in each browser profile you want to protect. For the bundled development extension and Edge setup, follow the browser setup guide.

A website is still blocked after my session

Check Time limits in Still: a daily allowance or bedtime can block a site outside a focus session. If the extension lost its connection, it keeps its last confirmed session rules. Restart Windows protection from Still’s Settings so the guard can confirm release. If you’re stuck, follow the recovery steps.

A selected website isn’t blocked

Check that the session is active, the companion is connected in the browser profile you’re using, and the correct domain is selected. A domain includes its subdomains, but a different domain needs its own entry. See more troubleshooting.

I want to remove Still

Finish or release your active session first. Follow the removal instructions for the Windows app, and remove the companion from Chrome’s extensions page. Use the recovery guide if protection is stuck.

Ask a question. Report a problem.

We use GitHub issues for support, bug reports and feature requests. Browse existing reports first, or open a new one. You’ll need a free GitHub account to post and follow replies.

For a bug report, please include:

  • Your Still app version and extension version (shown on Chrome’s extensions page).
  • Your Windows and Chrome versions, plus the extension’s connection status.
  • What you were trying to do, the steps that reproduce it, and what happened instead.
  • The exact error message and, if useful, a screenshot with personal details removed.
GitHub issues are public. Don’t include passwords, private URLs, browsing history or personal information. Only share the details needed to explain the problem.
