NOT INSTALLED

Still Guard runs independently of this window. Sessions and release delays survive closing the app and restarting Windows.

Before you enable protection

Administrator approval installs a small Windows service. Desktop apps use file-path and file-hash rules; Store apps use package rules for your Windows account. Apps already running are closed when you start; save your work first.

An administrator can override local controls. Other accounts and modified desktop binaries are outside this protection. Store apps use their package identity. Still does not change existing organization policies.

A LITTLE SPACE FOR YOUR ATTENTION
Connect Chrome & Edge once

The Still companion provides immediate blocks, closes already-open blocked pages, and shows your chosen screen. Install it in each browser profile you use. Windows browser policies apply across Chrome/Edge profiles on this PC and add a fallback, including restrictions on private and guest browsing; policy refresh can be delayed. Restart browsers after setup. Keep a connected browser open when a website session or scheduled alert starts; Still waits for the companion to confirm its blocking rules.

  1. Open chrome://extensions or edge://extensions in your browser.
  2. Enable Developer mode, choose Load unpacked, and select the folder opened by Still.
  3. In the Still extension’s Details, enable Allow in incognito (Chrome) or Allow in InPrivate (Edge).
  4. Repeat for the other browser and any additional profiles. Restart the browser. The Still extension should say “connected, ready to focus”.

Coverage is limited to Chrome and Edge on this PC. Administrators, other browsers, remote browsing/proxy websites, and removal of the development companion can bypass parts of this protection. Windows policies still provide domain blocking after the companion is removed, once the browser has refreshed its policies.
