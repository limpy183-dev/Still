Windows protection

NOT INSTALLED

Still Guard runs independently of this window. Sessions and release delays survive closing the app and restarting Windows.

Before you enable protection

Administrator approval installs a small Windows service. Desktop apps use file-path and file-hash rules; Store apps use package rules for your Windows account. Apps already running are closed when you start; save your work first.

An administrator can override local controls. Other accounts and modified desktop binaries are outside this protection. Store apps use their package identity. Still does not change existing organization policies.
