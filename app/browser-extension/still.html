STILL · WEBSITE FOCUS

A gentler way back to focus.

Put distracting websites on hold, give them a daily limit, and choose what you see instead.

For more control, add Still for Windows.

On its own, this extension blocks websites, and you can end its sessions whenever you like. Still for Windows also blocks apps, starts sessions on a schedule, and runs sessions you can’t end early, even by turning this extension off. It’s free, and we recommend using the two together.

Get Still for Windows ↗

To block websites in private windows too, open this extension’s Details page and turn on Allow in Incognito (in Edge: Allow in InPrivate).
